# Pengantar Selenium WebDriver  

## Apa Itu Selenium?  
**Selenium** adalah framework *open-source* untuk melakukan **automasi browser web**.  

### Fitur Utama Selenium:  
- Mendukung banyak bahasa (Python, Java, C#, JS).  
- Dapat dijalankan di berbagai browser.  
- Gratis dan open-source.  
- Kompatibel di berbagai platform.  
- Terintegrasi dengan framework testing lain.  

---

## Apa Itu Selenium WebDriver?  
**WebDriver** berfungsi sebagai penghubung antara kode pengujian dan browser.  
Memungkinkan kontrol penuh atas browser untuk melakukan klik, input, dan validasi elemen.

---

## Mengapa Menggunakan Selenium?  
1. Gratis dan open-source.  
2. Mendukung banyak bahasa & browser.  
3. Bisa diintegrasikan dengan framework testing.  
4. Komunitas besar & dokumentasi lengkap.  

---

## Instalasi Selenium dengan Python  
1. Instal Python.  
2. Jalankan:  
   ```bash
   pip install selenium
   ```  
3. Unduh WebDriver sesuai browser (ChromeDriver, GeckoDriver).  
4. Pastikan driver ada di PATH.  

---

## Contoh Skrip Python  
```python
from selenium import webdriver
driver = webdriver.Chrome()
driver.get("https://www.saucedemo.com")
driver.quit()
```

---

## Interaksi dengan Elemen HTML  
```python
from selenium import webdriver
from selenium.webdriver.common.by import By

driver = webdriver.Chrome()
driver.get("https://www.saucedemo.com")

driver.find_element(By.ID, "user-name").send_keys("standard_user")
driver.find_element(By.ID, "password").send_keys("secret_sauce")
driver.find_element(By.ID, "login-button").click()
```

---

## Contoh Test Scenario  
- **TS001:** Login berhasil → tampil halaman *inventory*.  
- **TS002:** Login gagal → tampil pesan error.  
- **TS003:** Tambah produk ke keranjang → jumlah item bertambah.

## Kesimpulan  
**Selenium WebDriver** memungkinkan pengujian otomatis yang realistis dan efisien.  
Dengan menguasainya, QA dapat menghemat waktu dan meningkatkan akurasi pengujian web.
