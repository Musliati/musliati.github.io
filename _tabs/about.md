# Tentang Saya

Halo! Saya **Musliati**, mahasiswa **Program Studi Sistem Informasi** yang bersemangat menjembatani dunia teknologi dengan kebutuhan bisnis. Portofolio ini saya buat untuk **mendokumentasikan perjalanan akademik** saya — mulai dari tugas perkuliahan, proyek praktikum, penelitian kecil, hingga pengalaman mengembangkan aplikasi.

Selama studi, saya fokus mempelajari dan mengaplikasikan konsep seperti:
- **Analisis dan perancangan sistem** (flowchart, UML, use case)
- **Perancangan basis data & SQL**
- **Pengembangan aplikasi web (CRUD, autentikasi, API sederhana)**

Saya percaya proses belajar terbaik terjadi saat mengerjakan proyek nyata. Oleh karena itu, saya aktif mengumpulkan dokumentasi proyek — mulai dari requirement, desain, hingga implementasi dan refleksi pembelajaran — agar setiap pengalaman menjadi referensi untuk perbaikan ke depan.

## Keterampilan singkat
- Analisis Sistem & Pemodelan (ERD, UML)  
- Basis Data (MySQL, perancangan normalisasi)  
- Pengembangan Web dasar (HTML, CSS, PHP / atau framework sederhana)  

## Tujuan Akademik
Saya ingin terus mengembangkan kemampuan teknis dan analitis sehingga kelak dapat berkontribusi pada pengembangan sistem informasi yang efisien dan ramah pengguna. Portofolio ini akan terus diperbarui seiring perjalanan akademik dan proyek yang saya selesaikan.
